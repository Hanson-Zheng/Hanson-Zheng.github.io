# Welcome to my homepage.
Please visit https://hanson-zheng.github.io/index.html for the rendered webpages.

## Projects

- `projects.html` lists all project folders in `data/projects.js`, grouped by year (newest first). Within a year, projects retain the order from that file. `featured` only controls inclusion in the Home carousel.
- Edit the existing `project/<folder>/project.json`: `card.title`, `card.image`, `card.imageAlt`, `summary`, and `topics` supply the listing cards. The listing starts with the project title; `card.category` remains searchable without appearing as a subtitle. Grouping uses `year`, falling back to `card.year`; projects without a year appear under “Other projects”.
- The desktop listing places a 16:9 image on the right; on mobile the image appears above the text. The Home carousel retains its existing card layout.
- Related publications are read from `data/publications.js` via each paper's `links.project`. All matching papers with a valid DOI appear as linked titles with a small publication icon. Projects without a paper simply omit that area. An optional `publicationId` also associates a project with a specific paper.
- Each related paper is prefixed with a small venue/year label, for example `IEEE ICRA · 2026`. Set the optional `venueShort` in the individual paper source to customize the abbreviation; it falls back to `venue`, and hovering shows the full venue name. Multiple papers use their own venue and year.
- A single related paper stays inline. With two or more, each paper has its own full-width row, venue/year above the full title, a publication icon and external-link arrow, and a fine divider between rows. Desktop and mobile use the same reading order; all papers remain visible and titles wrap without truncation. Their order follows the generated publication data.
- Continue maintaining individual papers in `data/publications/` and running `merge_publications.py` to regenerate the publication data. Project content and cover images remain in their own project folders.
- Search covers project titles, summaries, topics, section text, and related paper titles, authors, venues and abstracts. Nonmatching projects and empty years are hidden. Matches within longer project/paper text show a short excerpt. Clear search or press Escape to restore the full list.
- The mobile sidebar becomes a search field and horizontally scrollable year navigation above the cards. Both themes and reduced-motion preferences are supported.
- Listing styles: `css/project-directory.css`; rendering/search: `js/project-directory.js`; shared project/publication association: `js/project-data.js`.
- `css/collections.css` owns the shared Projects/Publications search controls, year navigation, and page headings (also used by Highlights). All three retain Inter. Project card titles match publication titles at `1.15rem / 600`; summaries use `1rem` and the main body text color. Topic labels and related-paper text are larger and darker than the initial prototype, in both themes.
- `css/cards.css` defines shared card interactions for Projects, Publications, Highlights and the Home carousel (and future Life cards). With a mouse, cards rise `3px`, use a restrained blue-grey border and soft shadow, and images scale to `1.02` over `260ms`. Keyboard focus uses the same border/shadow without movement. Touch devices do not get hover motion, and reduced-motion mode disables movement/zoom. Listing cards use `12px` corners; the Home film strip retains `9px` corners and its existing 16:9 / 96px caption dimensions. This replaces the separate effects (Highlights: `6px` lift; Home: `1.035` image scale; Projects: `1.025`; Publications: shadow only).
